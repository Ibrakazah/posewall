# PoseWall

Рабочая версия: **https://posewall.vercel.app/**. Размещена на Vercel и не зависит от включённого компьютера разработчика. Для камеры открывай HTTPS-ссылку в браузере телефона и разреши доступ.

### Обновление интерфейса

Выбран дизайн «Движение»: светлый фон, графитовая типографика и оранжевый акцент. В игре крупный образец позы, небольшое превью камеры, заметный таймер и конкретная подсказка. Видео и скелет показываются без зеркального отражения. Повторная попытка использует уже загруженную модель и калибровку; выход на главную выключает камеру. Если браузер не отвечает на запрос камеры, через 30 секунд появляется возможность повторить попытку.

### Деплой на Vercel

Из корня именно PoseWall: `npx vercel link`, затем `npx vercel deploy --prod`. Сборка: `npm run build`, каталог: `dist`. Настройки находятся в `vercel.json`; `.vercelignore` исключает соседние проекты, макеты, резервные копии и локальные секреты. Модель и WASM входят в `public` и раздаются с того же домена. Тесты `npm test` ограничены исходниками PoseWall.

**Камера вместо джойстика.** Браузерная motion-игра для ADMIT Hackathon: принимай позу, чтобы пройти через приближающуюся стену. Направление — игра. Один забег: 10 стен, 3 жизни, около 80 секунд до финала.

## Три режима

- **Разминка:** четыре движения для плеч и корпуса, по пять секунд устойчивого удержания. Система показывает конкретную коррекцию позы.
- **Стена:** исходная законченная игра на 10 раундов. Стена приближается к игроку; нужно принять форму выреза, сохранив три жизни и набрав максимум очков.
- **Приседания:** счётчик повторов и контроль техники. Ракурс спереди следит за направлением коленей и симметрией; ракурс сбоку — за глубиной и наклоном спины. Повтор засчитывается только после нижней точки и полного подъёма.

На стартовом экране режим можно выбрать карточкой или жестами. После включения камеры мах поднятой рукой влево/вправо перемещает выделение, а удержание руки выше плеча около секунды открывает выбранный режим.

## Запуск

Нужны Node.js 22 LTS или новее и npm. У игрока — актуальный Chrome/Edge и веб-камера; установка приложения не нужна.

```bash
npm install
npm run dev
```

Открой http://localhost:5173. Для production:

```bash
npm test
npm run build
npm run preview
```

Папка `dist/` готова для статического HTTPS-хостинга. Команда сборки — `npm run build`, выходная папка — `dist`. Для размещения в подпапке: `npm run build -- --base=/repository-name/`. Worker, WASM и модель загружаются с того же сайта. Не открывай `index.html` через `file://`. Камера на телефоне требует HTTPS: обычный HTTP-адрес ноутбука в локальной сети не подходит.

## Режим «Ошибка» — собственная логика

MediaPipe Pose Landmarker Lite возвращает только координаты и видимость точек тела. Собственный движок выполняет дальнейшую обработку: нормализует координаты, считает углы суставов и положение корпуса, сравнивает метрики с правилами поз, сглаживает координаты и выбирает наиболее полезную конкретную подсказку. Красные сегменты показывают часть тела, которую нужно исправить. Видео и точки не отправляются на сервер.

## Архитектура

React + TypeScript + Vite, SVG-маски стен, Canvas-скелет, MediaPipe Tasks Vision, Web Audio API. Бэкенда нет.

```text
src/game/poses.ts           декларативные правила и восемь силуэтов
src/game/evaluator.ts       нормализация, видимость, метрики, оценка
src/game/errorAnalyzer.ts   выбор главной подсказки
src/game/hold.ts            непрерывное удержание
src/game/session.ts         очки, жизни, серия, результаты раундов
src/hooks/useTracking.ts   камера, worker, сглаживание, ошибки, очистка
src/components/            силуэт/стена и скелет
src/App.tsx                экраны и игровой цикл
```
